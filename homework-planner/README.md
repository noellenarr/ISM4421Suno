# 📚 Homework Planner

A simple app to keep track of homework and to-dos on a calendar.

## Features
- Month calendar that shows what is due each day
- Add assignments with class, type, due date, time, priority, and notes
- Checklists: break an assignment into steps and check them off (with a progress bar)
- Reminders: pop-up and browser notification before something is due (keep the tab open)
- Filters: Selected day, Upcoming, Overdue, Done, All
- Saves in your browser, so your list is still there when you come back
- Works on phones and has a dark mode

## Files
- `index.html` – the page layout
- `style.css` – the look
- `app.js` – how it works (calendar, checklists, reminders, saving)
- `netlify.toml` – tells Netlify to publish this folder

## Deploy on Netlify
In Netlify: **Add new site → Import an existing project → GitHub**, pick this repo,
and set **Base directory** to `homework-planner`. Leave the build command empty.
